# Verteilen 2 Common

A common library for verteilen 2 applications

## Purposes

In order to prevent writing the same code in every applications.\
I seperate the basic stuff into a core library.\
THis way it's easier to sync with states and it also follows the DRY principle.

## Features

- [x] All data structures.
- [x] Protobuf definitions.
- [x] Get network interface ipv4, ipv6 list.
- [x] Get home directory path.

## proto_gen.sh

This generate the proto-buf .c and .h files to

* include/verteilen2/proto_gen
* src/verteilen2/proto_gen
