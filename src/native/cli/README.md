# Verteilen 2 CLI

A CLI tools to manage applications

## Usages

### Show all the available commands

```bash
verteilen-2-cli --help [module]
verteilen-2-cli --h [module]
```

### Show the module command details

```bash
verteilen-2-cli --help client
verteilen-2-cli --h client

verteilen-2-cli --help server
verteilen-2-cli --h server

verteilen-2-cli --help master
verteilen-2-cli --h master
```

### Simple commands to use

```bash
verteilen-2-cli --status [module]
verteilen-2-cli --healthcheck [module]
```

You can leave module part empty for display all
