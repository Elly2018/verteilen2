# Dependencies

These are the Dependencies library i'm using

### argh

A tool for quick analysis command line arguments, and form a structure data for easier state or environment change.

### crow

A web framework support HTTP server, with cookies and session manager and websocket support.

### icmplib

A ping library, quick way to check if the ip address is enable to get ping. Or mDNS purposes.

### json

Json format data string serializer.

### libhv

A low-level websocket library. crow can only handle web websocket, But i need a way to let application communicate each other.

### spdlog

For log, beautiful log messages for sure.

### sqlite

A c++ library for sqlite3. Better storage than a plain json files.

### uuid

A UUID string generator.
